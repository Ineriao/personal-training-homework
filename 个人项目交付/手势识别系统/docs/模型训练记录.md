# 模型训练记录

## 1. 训练配置

| 项目 | 配置 |
| --- | --- |
| 任务 | YOLO 目标检测 |
| 基础模型 | YOLO11n 预训练权重 |
| 训练轮数 | 100 |
| 输入尺寸 | 320 |
| 批大小 | 64 |
| 类别数 | 5 |
| 优化方式 | Ultralytics 默认配置 |
| 混合精度 | 开启 |
| 最佳权重 | `models/best.pt` |

原训练参数记录中的设备为 `0`，训练使用 CUDA 完成。交付检查时当前可复现环境检测到的是 `torch 2.5.1+cpu`，CUDA 不可用，因此不能把当前运行环境描述为 CUDA 环境。模型权重和原训练结果保留不变。

## 4. 训练结论

当前模型能够完成五类静态手势的检测，测试集指标达到课程演示要求。实际部署时仍应增加真实场景样本，特别是低光照、遮挡、手势尺度变化和复杂背景样本，并重新验证泛化能力。
