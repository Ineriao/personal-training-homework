# 静态手势识别系统软件设计

## 1. 系统结构

```text
图片文件
   |
   v
PyQt5 图片选择与预览
   |
   v
InferenceWorker 工作线程
   |
   v
Ultralytics YOLO 模型
   |
   v
检测结果整理与绘制
   |
   +--> 标注图片预览
   +--> 结果表格
   +--> 统计信息和状态栏
```

## 2. 模块设计

| 模块 | 实现位置 | 职责 |
| --- | --- | --- |
| 程序入口 | `app/gesture_monitor.py:main` | 创建 `QApplication` 并显示主窗口。 |
| 主窗口 | `GestureMonitor` | 管理布局、按钮、预览图和结果状态。 |
| 推理工作对象 | `InferenceWorker` | 在线程中加载模型并执行图片推理。 |
| 模型推理 | `InferenceWorker.predict` | 调用 YOLO `predict`，整理类别和置信度。 |
| 图像转换 | `show_prediction` | 将 OpenCV BGR 图像转换为 Qt RGB 图像。 |
| 结果统计 | `Counter` | 统计目标数量和出现次数最多的手势。 |

## 3. 类和接口

### 3.1 `InferenceWorker`

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `__init__(model_path)` | 模型文件路径 | 工作对象 |
| `predict(image_path, confidence)` | 图片路径、置信度阈值 | `completed` 信号，携带图像和检测列表 |
| `failed` | 错误文本 | 发送到主窗口的错误处理槽 |

模型对象采用延迟加载方式，只在第一次识别时加载一次，避免每次点击都重复读取权重。

### 3.2 `GestureMonitor`

| 接口 | 作用 |
| --- | --- |
| `open_image()` | 打开图片并刷新预览 |
| `start_prediction()` | 检查输入和模型后发起推理 |
| `show_prediction()` | 更新标注图、表格和统计信息 |
| `show_error()` | 显示推理失败信息 |
| `clear_content()` | 清除图片和识别结果 |
| `closeEvent()` | 退出时停止并等待工作线程 |

## 4. 路径设计

程序通过 `Path(__file__).resolve()` 获取交付包根目录，不依赖运行时的当前工作目录。

```text
app/gesture_monitor.py
models/best.pt
samples/demo.jpg
outputs/predictions/
```

模型路径为 `models/best.pt`。预测脚本的输出路径为 `outputs/predictions`。

## 5. 配置设计

`config/system.example.json` 保存模型路径、输入样例、置信度、输入尺寸、设备和类别信息。当前界面版本将模型推理参数写在程序中，示例配置用于后续配置化改造，不影响当前运行。

训练数据配置使用 `config/data.yaml`，类别编号为：

```text
0 fist
1 like
2 ok
3 palm
4 peace
```

## 6. 线程设计

主线程负责窗口和控件。`InferenceWorker` 被移动到 `QThread` 中，通过 Qt 信号槽传递开始推理、识别完成和识别失败事件。主线程不直接执行模型推理，避免界面在推理期间无响应。

## 7. 数据库设计

当前版本不使用数据库。输入图片、模型文件和输出图片使用文件系统保存，适合静态图片演示。后续如需保存历史识别记录，可增加 SQLite 表：`record_id`、`image_path`、`gesture_name`、`confidence`、`created_at`。
