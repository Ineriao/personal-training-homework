# 数据集与标注说明

## 1. 数据来源

项目使用 HaGRID Sample 30k 384p 数据，从中筛选 `fist`、`like`、`ok`、`palm`、`peace` 五类手势。原始压缩包和完整处理过程保存在每日作业目录，不放入最终交付包。

## 2. 数据规模

| 数据集 | 图片数量 |
| --- | ---: |
| train | 2100 |
| val | 600 |
| test | 300 |
| 合计 | 3000 |

每张图片对应一个 YOLO TXT 标注文件，训练、验证和测试图片与标注文件的文件名主干一致。

## 3. 类别编号

| 编号 | 类别 |
| ---: | --- |
| 0 | fist |
| 1 | like |
| 2 | ok |
| 3 | palm |
| 4 | peace |

## 4. 标注格式

每行包含五个值：

```text
class_id center_x center_y width height
```

四个坐标均已归一化到 `0` 到 `1`。`validate_dataset.py` 会检查图片和标注是否一一对应、类别编号是否有效、坐标是否越界以及框的宽高是否大于零。

## 5. 数据处理流程

1. 从压缩包内读取图片和 JSON 检测框。
2. 只保留五个目标类别。
3. 将左上角坐标和宽高转换为 YOLO 中心点格式。
4. 使用固定随机种子划分 train、val、test。
5. 检查图片数量、标注数量和坐标范围。
6. 使用训练脚本读取 `data.yaml`。

## 6. 数据质量要求

- 同一张图片不能重复出现在不同数据集。
- 标注框应完整覆盖手部目标。
- 训练集、验证集和测试集都应包含五类手势。
- 测试集应保持独立，不能使用训练过程中的图片替代。
