## 5. 问题清单

| 编号 | 问题 | 当前处理 |
| --- | --- | --- |
| P-01 | 当前环境为 CPU 版 PyTorch，不能复现原 CUDA 训练速度 | 保留原训练记录，运行时自动选择 CPU；需要 CUDA 时安装匹配版本的 PyTorch |
| P-02 | 当前界面只支持静态图片 | 符合第一阶段范围，视频识别列入后续扩展 |
| P-03 | 交付包没有完整数据集 | 为控制体积，保留数据处理脚本和数据说明，完整数据留在每日作业目录 |

## 6. 测试结论

项目核心功能、数据检查、模型文件和交付目录结构满足静态手势识别演示要求。发布前应在目标电脑上重新安装依赖并实际打开界面，确认 Qt 平台插件和显卡驱动与目标环境匹配。
