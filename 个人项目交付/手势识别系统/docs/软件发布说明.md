# 软件发布说明

## 1. 发布内容

发布目录为 `手势识别系统`，包括：

- PyQt5 图形界面源代码。
- YOLO11n 最佳模型权重。
- 命令行预测和数据检查脚本。
- 数据转换和训练源代码。
- 配置示例、样例图片和启动脚本。
- 训练评价图和项目交付文档。

当前发布形式为 Python 源码加启动脚本。检查现有环境时未发现 PyInstaller，因此没有把未验证的 `.exe` 文件放入交付包。`release/启动手势识别.bat` 已作为 Windows 启动入口完成验证。

## 2. 安装步骤

1. 安装 Python 3.11。
2. 在项目根目录创建并激活虚拟环境。
3. 安装 `requirements.txt` 中的依赖。
4. 确认 `models/best.pt` 存在。
5. 运行 `python app/gesture_monitor.py` 或双击 `release/启动手势识别.bat`。

## 3. 运行步骤

1. 启动程序。
2. 点击“打开图片”。
3. 选择 JPG、JPEG、PNG 或 BMP 图片。
4. 点击“开始识别”。
5. 在右侧表格查看类别和置信度。
6. 需要重新识别时重新打开图片即可。

## 4. 命令行运行

```bash
python scripts/predict_gestures.py --source samples/demo.jpg --model models/best.pt
```

结果写入 `outputs/predictions`。数据检查脚本需要完整数据集目录：

```bash
python scripts/validate_dataset.py --dataset dataset
```

## 5. 设备说明

程序会检测 PyTorch 是否能够使用 CUDA。CUDA 可用时使用设备 `0`，否则自动使用 CPU。CPU 可以完成静态图片识别，但速度会低于 CUDA 环境。

## 6. 常见问题

### 找不到 Qt 平台插件

确认 PyQt5 安装完整，并使用当前虚拟环境的 Python 启动程序，不要混用系统 Python 和其他项目环境。

### 找不到模型文件

确认 `models/best.pt` 存在，启动目录结构不能被打乱。

### 预测没有目标

降低置信度参数，检查图片中是否有清晰、完整的手部目标，并确认图片场景与训练数据差异不大。

## 7. 生成 Windows 可执行文件

如果目标电脑需要单文件或目录式可执行文件，可在已经安装依赖的环境中执行：

```bash
python -m pip install pyinstaller
pyinstaller --noconfirm --windowed --name GestureMonitor --add-data "models;models" --add-data "samples;samples" app/gesture_monitor.py
```

打包后应在目标电脑重新检查 Qt 平台插件、模型加载和图片识别，不能只以打包命令成功作为发布验收依据。
