# 静态手势识别项目计划

## 1. 项目目标

使用目标检测模型识别图片中的手部区域和静态手势类别，并通过图形界面展示识别结果。第一阶段只处理单张图片，不涉及连续手势动作、手语语义理解和视频时序建模。

## 2. 工作阶段

| 阶段 | 工作内容 | 输出 |
| --- | --- | --- |
| 需求确认 | 确定识别类别、输入方式和交付范围 | 需求分析、用例和术语表 |
| 环境准备 | 配置 Python、PyTorch、Ultralytics、PyQt5 | 依赖说明、环境记录 |
| 数据准备 | 筛选五类 HaGRID 样本，转换为 YOLO 标注并划分数据集 | `dataset`、`data.yaml` |
| 模型训练 | 使用 YOLO11n 迁移学习训练 | `best.pt`、训练曲线 |
| 模型评价 | 使用独立测试集计算 Precision、Recall、mAP | 评价指标和混淆矩阵 |
| 界面开发 | 完成图片选择、结果预览和识别结果表格 | `gesture_monitor.py` |
| 测试发布 | 进行功能、异常和环境测试，整理运行包 | 测试报告、发布说明、交付包 |

## 3. 已完成范围

- 五类静态手势数据整理和 YOLO 格式转换。
- 训练集、验证集和测试集划分。
- YOLO11n 迁移学习训练 100 轮。
- 独立测试集评价和预测结果生成。
- PyQt5 图片识别界面。
- 相对路径运行包和必要交付文档。

## 4. 暂不包含范围

- 视频连续帧手势跟踪。
- 手势动作序列识别。
- 语音播报和控制外部设备。
- 用户账号、数据库和远程部署。
